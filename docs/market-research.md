# 競合調査と方針案（2026-11-21）

App Store の検索結果の概要をもとにした競合調査と、それを踏まえた方針案。

> 注意：調査は App Store の検索結果の概要に基づいており、ダウンロード数や各アプリの中身までは確認していない。

## 前提（決定済み）

- フレームワーク：Flutter
- 最初の対象試験：AWS Certified Solutions Architect – Professional（SAP）
- 将来は AWS の他の認定試験にも広げる（全冠を目指す本人の学習と連動）
- 収益化の基本は広告（AdMob）

## 競合調査の結果

| アプリ | 対象 | 価格・収益 | 特徴 |
| --- | --- | --- | --- |
| ソリューションアーキテクト模擬試験アプリ（Naohito Muraoka） | SAA | 無料＋アプリ内課金 | 約330問、評価4.4（約800件）。SAAの定番 |
| AWS ソリューションアーキテクトアソシエイト 問題集（キイロ乃カモ） | SAA（CLF版もあり） | 買い切り¥300 | 広告なし・全問解説・オフライン可・苦手分野のレーダーチャート |
| CloudCert（SAA版・CLF版） | SAA / CLF | 無料 | 500問、本番形式の模擬試験（65問・130分）、復習モード |
| クラウドプラクティショナー一問一答（Akira Kurebayashi） | CLF | 有料 | 一問一答形式、全解説にAWS公式ドキュメントへのリンク、資格保持者が作成と明記 |
| Learnify | AWS 12種＋Azure | サブスク | 約5000問、生成AIによる解説・学習分析 |
| Cloud Pass | AWS＋GCP 24種以上 | 有料 | 全試験対応型 |

### 分かったこと

- 競合は CLF・SAA に集中しており、**日本語の SAP 専用アプリは見つからなかった**
- 多くのアプリが「広告なし」を売りにしている
- 問題数では AI 生成系（数千問規模）に勝てないので、質で差別化する必要がある
- 「資格保持者が作成」「公式ドキュメントへのリンク」で信頼性を示しているアプリがある

## 方針案

### 決定

- **SAP から始める**（競合が少ないため）
- **アプリ名に「AWS」を主役として入れない**。AWS の商標ガイドラインでは、AWS の商標を他社製品に混同を招く形で使うことや、提携・承認を暗示する使い方、自社ブランドより目立たせる使い方が禁止されている。アプリ名は独自ブランドにし、「AWS認定SAP対策」などはサブタイトル・説明文・キーワードで表現する
- **ストアの説明文とアプリ内に免責文を入れる**。例：「本アプリはAmazon Web Services, Inc.とは提携していません。AWSおよびAWS認定はAmazon.com, Inc.またはその関連会社の商標です。」
- **差別化の軸は質**。具体的には次の2つ
  - SAP の長いシナリオ問題を、設計判断のポイントごとの一問一答に分解する（スマホで読みやすくするため）
  - 全問の解説に AWS 公式ドキュメントへのリンクを付ける

### 未決（本人に確認すること）

- アプリ名（候補：クラ問 / くもドリル / スキマ認定 / ワンタップ認定）
- 収益化の形：「無料＋広告」に「広告を消す買い切り（数百円）」を加えるかどうか。広告なしを求める層を取りこぼさないための案
- 作者の立場の書き方：SAP 合格前に公開する場合、「SAP合格を目指しながら作った問題集」のように正直に書く案
- 苦手分野の可視化（レーダーチャートなど）や模擬試験モードを、v1 に入れるか後回しにするか

## 注意

- 問題文は必ずオリジナルで作ること。他の問題集や実際の試験問題を写さない
