# 実機確認の手順（iPhone）

シミュレーターではタップの操作を確かめられなかったので、実機で一通り触って確認する。気づいたことは最後の「メモ」に書いておけば、次の作業でそのまま直せる。

## 1. 準備（最初の1回だけ）

1. iPhone を USB で Mac につなぎ、iPhone 側で「このコンピュータを信頼」を選ぶ
2. iPhone の「設定 → プライバシーとセキュリティ → デベロッパモード」をオンにする（再起動が入る）
3. 署名の設定：`open ios/Runner.xcworkspace` で Xcode を開き、Runner → Signing & Capabilities で Team に自分の Apple ID を選ぶ
   - まだ Team が設定されていない（`project.pbxproj` に `DEVELOPMENT_TEAM` が無い）ので、この作業が必要
   - Apple Developer Program に未登録でも、無料の Apple ID（Personal Team）で入れられる。ただし**7日で起動できなくなる**ので、そのときは入れ直す
   - バンドルID `com.tmando616.certstack` が使えないと言われたら、その内容をメモしておく（公開用の ID なので、勝手に変えない）
4. 初回の起動で「信頼されていないデベロッパ」と出たら、iPhone の「設定 → 一般 → VPN とデバイス管理」で自分の Apple ID を信頼する

## 2. アプリを入れる

```bash
flutter devices                      # iPhone の ID を確認
flutter run -d <iPhoneのID> --release
```

- `--release` にすると、普段使うときと同じ速さで動く（デバッグ版は遅く、DEBUG の帯も出る）
- 広告は**テスト用の広告**が出る（本番の ID はまだ入れていない）。テスト用なので、タップしても規約違反にはならない
- 広告なしで確かめたいときは `--dart-define=ADS=false` を付ける

## 3. 確認すること

チェックを付けながら進める。おかしいところは画面のスクリーンショットを撮っておく。

### 起動と広告の同意
- [ ] 初回の起動で、広告の同意画面が出て「Continue」を押せる
- [ ] そのあと、トラッキングの許可のダイアログ（ATT）が出る（「あなたの興味に合った広告を表示するために使います…」の文面）
- [ ] 許可しても、許可しなくても、そのまま使える
- [ ] 出題画面の下にバナー広告が出る。出た瞬間に選択肢の位置が跳ねない

### ホーム
- [ ] 全冠ボードの枠をタップすると取得済みの印が付き、判子の動き（大きくなってから縮む）が出る。もう一度タップで外れる（外すときは動かない）
- [ ] 「今日の学習」の問題数と連続日数が、解いた数に合わせて増える
- [ ] 「目標 10問 ⌄」をタップして、目標を変えられる
- [ ] 「続きから解く」で、最後に解いた試験の一問一答が始まる

### 一問一答
- [ ] 選択肢をタップすると、正解・不正解の色に変わる（一瞬で切り替わる動き）
- [ ] 回答すると「正解・不正解」の見出しまで自動でスクロールする
- [ ] 解説が長いとき「続きを見る ↓」が出て、押すと最後まで進む
- [ ] 「次へ」でカードが横にめくれる
- [ ] 「元の問題に挑戦」「ポイント別の一問一答」「類題に挑戦」のボタンが動く

### 本番形式・分野を選んで解く
- [ ] 「分野を選んで解く」のシートで、複数の分野を選んで始められる
- [ ] タブ表示の「選択肢へ」ボタンで選択肢に移れる
- [ ] 選択肢のスワイプ表示で、選んだときのチェックが見え、枠線が切れていない

### 模試
- [ ] 開始の確認ダイアログ → 選択 → 前後の移動 → 一覧 → 採点の確認 → 結果、まで進める
- [ ] 途中で戻ろうとしたとき、中断の確認が出る
- [ ] 結果画面の分野ごとの正答率が出る

### 今回追加したもの（試験トップ）
- [ ] 1問以上解くと、「分野ごとの正答率」の上にレーダーチャートが出る。軸の番号と、下の一覧の「1. 分野名」が対応している
- [ ] 「間違えた問題だけ解き直す」に、間違えた問題の数が出る。解き直して正解すると、その問題が数から外れる
- [ ] 「この試験は取得済み」のスイッチが、ホームの全冠ボードに反映される

### 外部のアプリとの連携
- [ ] 解説の根拠リンクをタップすると、ブラウザで AWS のドキュメントが開く
- [ ] 「この問題の誤りを報告」でメールアプリが開き、宛先が `tmando616.apps+certstack@gmail.com` になっている
- [ ] 「このアプリについて」→「ライセンス」が開く

### 全体の使い心地（通勤電車で使う想定で）
- [ ] 片手で、親指だけで回答と「次へ」まで操作できる
- [ ] 文字の大きさ・行間は読みやすいか（揺れる中を想定）
- [ ] iPhone をダークモードにしても見やすい
- [ ] iPhone の文字サイズを大きくしても、表示が崩れない
- [ ] ホーム画面のアプリ名が「CertStack」になっている

### 問題の中身（時間があれば）
- [ ] 受ける予定の DVA・SOA・SAP を数問ずつ解き、問題文が分かりにくいもの・答えに納得できないものをメモする。問題番号は画面に出ていないので、「この問題の誤りを報告」でメールの下書きを作る（問題番号と問題文が自動で入る。自分宛てに送るか、下書きのままでよい）か、問題文の最初の一文をメモする
