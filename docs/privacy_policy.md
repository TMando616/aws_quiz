「クラウド認定」（以下「本アプリ」）は、本アプリの利用者の情報を以下のとおり取り扱います。

## 1. 本アプリが保存する情報

本アプリは、次の情報を**利用者の端末の中だけ**に保存します。開発者のサーバーへは送信しません。

- 問題への解答の記録（正誤、解答日時）
- 模試の結果
- 「取得済み」にした試験と、その日付
- 画面の表示方法の設定

これらの情報は、本アプリを削除すると端末から消去されます。

本アプリには会員登録の機能はなく、氏名・メールアドレスなどの入力を求めることはありません。

## 2. 広告について

本アプリは、Google LLC が提供する広告配信サービス「Google AdMob」を利用しています。Google AdMob は、広告の配信・効果測定・不正防止のために、次のような情報を収集することがあります。

- 広告識別子（iOS の IDFA、Android の広告 ID）
- IP アドレス、端末の種類、OS のバージョンなどの端末の情報
- 広告の表示やタップの状況

これらの情報は Google のプライバシーポリシーに従って取り扱われます。

- Google のプライバシーポリシー：https://policies.google.com/privacy
- Google によるデータの使用について：https://policies.google.com/technologies/partner-sites

### 利用者が選べること

- **iOS**：初回起動時に「トラッキングの許可」を求めます。許可しない場合も本アプリはすべて使えます（パーソナライズされない広告が表示されます）。あとから「設定」アプリの「プライバシーとセキュリティ」→「トラッキング」で変更できます。
- **欧州経済領域・英国などの利用者**：初回起動時に、広告のための情報の利用について同意を求めます。本アプリのメニューの「広告のプライバシー設定」から、いつでも選び直せます。
- **Android**：端末の「設定」から広告 ID のリセットや、パーソナライズ広告の無効化ができます。

## 3. 問い合わせ・問題の誤りの報告

本アプリから問い合わせや問題の誤りの報告をするときは、利用者の端末のメールアプリを使います。送られたメールアドレスと本文は、返信と問題の修正のためだけに使い、ほかの目的には使いません。

## 4. 第三者への提供

法令に基づく場合を除き、開発者が利用者の情報を第三者に提供することはありません（2. の Google AdMob による収集を除きます）。

内容を変更する場合は、このページで告知します。
